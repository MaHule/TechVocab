# TechVocab 码词

> 专为计算机与软件工程学习者打造的“专业技术词库 + 真实文档阅读”双闭环轻量英语学习小程序。

---

## 📖 项目简介

区别于传统“背考级单词、看日常例句”的通用背单词软件，TechVocab 专注于**计算机软硬件、底层系统、网络架构及工程代码**中的真实术语与语境，解决开发者“背了通用英语依然看不懂技术文档和报错信息”的核心痛点。

### 核心特性

- **计算机专属词库**：本地内置高频计算机专业词库，精准技术释义（避免把 	hread 译为“线头”，精准解析为“线程”）。
- **真实技术文档精读**：引入真实一手技术文章，支持**即点即查**、段落精读与生词高亮。
- **Local-First 本地优先**：核心数据本地化存储与秒级响应，零延迟离线体验。
- **闪卡记忆复习**：高效记忆卡片滑动与艾宾浩斯复习流。

---

## 🛠️ 技术选型

- **前端架构**：微信小程序原生开发 (WXML + WXSS + JavaScript)
- **设计规范**：纯纯技术范极客暗色/浅色现代规范，遵循设计 Tokens
- **无服务零运维**：Serverless 架构，搭配轻量数据处理管线 (scripts/)

## 🚀 快速开始

1. **克隆仓库**：
   `ash
   git clone <你的仓库地址>
   `
2. **导入项目**：
   - 打开 **微信开发者工具**
   - 选择 **导入项目**
   - 目录选择当前工程根目录（包含 project.config.json 的目录）
   - AppID 可使用自己的测试号或个人小程序 AppID
3. **运行预览**：
   - 在微信开发者工具中编译运行即可进行模拟器预览或真机调试。
