> **文档版本**：v1.0 (MVP Definition)  
> **文档状态**：已确认

---

## 1. 产品一句话定位

> **专为计算机与软件工程学习者打造的“专业技术词库 + 真实文档阅读”双闭环轻量英语学习小程序。**

区别于传统“背考级单词、看日常例句”的泛通用背单词 App，本产品彻底剔除日常生活无关语境，专注于**计算机软硬件、底层系统、网络架构及工程代码**中的真实术语与语境，解决程序员“背了通用英语依然看不懂一手英文技术文档和报错信息”的核心痛点。

---

## 2. 核心痛点与问题洞察

### 2.1 传统背单词 App 的“水土不服”
1. **语义严重错位**：
   * 在通用词典里，`argument` 是“争吵”、`thread` 是“绳线”、`table` 是“桌子”、`dump` 是“垃圾场”、`socket` 是“插座”；
   * 在计算机语境中，它们分别是**“实参”、“线程”、“数据表/二维表格”、“内存转储”、“套接字”**。传统 App 的释义直接误导编程初学者。
2. **专业术语严重缺失**：
   * 通用词库（四六级、托福、雅思）几乎不收录或极少侧重如 `idempotency`（幂等性）、`polymorphism`（多态）、`reentrancy`（重入）、`backpressure`（背压）等工程高频词。
3. **例句脱离真实工程**：
   * 通用例句多为日常生活对话，缺少**代码片段、编译/运行时报错日志、Git 提交记录、RFC 协议规范**等程序员每天面对的真实语境。

### 2.2 程序员在英文技术阅读中的卡点
* **查词打断心流**：在阅读英文官方文档、开源项目 Issue、技术博客时，频繁切换通用翻译工具极度割裂专注度。
* **缺少“阅读中巩固”与“生词再回炉”机制**：平时查过的技术生词随手关掉即忘，缺少结构化的收集和记忆复习机制。

## 3. 目标用户画像 (Target User Personas)

本产品兼顾**编程零基础初学者**与**进阶开发者**的渐进式成长需求，按阶段划分两大核心人群：

### 画像 1：转码人群 & 计算机低年级学生（零基础/筑基期）
* **人群属性**：非科班转码学习者、计算机/软件专业大一/大二学生。
* **英语起点**：具备基础英语能力（高中或四级水平），但对全英文开发环境、IDE 报错提示、代码语法关键字心存畏惧。
* **核心痛点**：
  * 遇到终端报错（如 `NullPointerException`, `deprecation warning`, `segmentation fault`）看不懂，习惯性依赖中文机翻；
  * 基础概念混淆（如 `parameter` vs `argument`、`declaration` vs `definition`、`traverse` vs `iterate`）。
* **诉求**：从最基础的编程语法词汇（`variable`, `loop`, `inherit`, `catch`）和高频报错词打底，建立编程英语自信，消除恐惧感。

### 画像 2：在职初中级程序员 & 计算机高年级/研究生（进阶成长型）
* **人群属性**：拥有 1~3 年工作经验的软件工程师、准备外企面试或阅读英文论文的开发者。
* **英语起点**：通过四六级，日常阅读简单技术文章无大碍，但精读海外官方文档（如 Kubernetes、PostgreSQL、Spring、Linux 内核）、RFC 规范时效率低。
* **核心痛点**：
  * 底层专业概念与系统级词汇积累零散，理解不够透彻；
  * 缺少体系化积累，专业术语在工作沟通中发音不准或不敢使用。
* **诉求**：按技术领域（网络、数据库、操作系统、分布式）系统化攻克进阶术语，能够直接无障碍精读一手技术文档。

## 4. 核心差异化价值与产品支柱 (Core Pillars)

```
┌────────────────────────────────────────────────────────┐
│               计算机英语核心通识与专项词库             │
│   (编程基础语法 -> 核心通识[网络/系统/算法/报错] -> 垂直扩展)│
└───────────────────────────┬────────────────────────────┘
                            │ 学习记忆
                            ▼
┌────────────────────────────────────────────────────────┐
│            技术卡片学习 (技术释义 + 代码真实语境)       │
└───────────────┬────────────────────────▲───────────────┘
                │                        │
       语境巩固 │                        │ 生词回炉复习
                ▼                        │
┌────────────────────────────────────────────────────────┐
│        技术文章阅读板块 (自主导入/粘贴 + 智能查词)     │
└────────────────────────────────────────────────────────┘
```

### 支柱 1：计算机专属第一释义词库（分级演进）
* **计算机第一语义优先**：过滤掉生活化义项，直接呈现计算机工程中的标准中文规范术语。
* **真实代码与工程例句**：
  * 每张单词卡片配备来自真实开源项目、官方文档、RFC 规范、典型编译报错的例句或微型代码段（Code Snippet）。
  * 标注易混淆概念的对比解析（例如 `Authorization` vs `Authentication`）。
* **词库分级与分类架构**：
  * **Level 1（入门基石）**：编程基础语法关键字、控制流、常见通用报错与提示；
  * **Level 2（核心通识 - MVP核心）**：计算机网络（TCP/IP、HTTP）、操作系统（进程/线程/内存）、数据结构与算法、数据库基础；
  * **Level 3（垂直进阶 - 后续扩展）**：前端工程、云原生/DevOps、AI/机器学习、网络安全（Security）。

### 支柱 2：“自主阅读 + 语境查词 + 生词回炉”闭环
* **支持外部文章自主导入/粘贴**：
  * 用户可直接粘贴正在阅读的技术博客、文档片段、开源 Issue 文本或文章链接；
  * 系统在阅读流中自动高亮其中的专业技术词汇，降低认知负荷。
* **极速点词/划词查询技术专属释义**：
  * 区别于传统查词弹窗展示几十种日常语义，小程序只展示最切合当前语境的计算机技术释义。
* **一键加入生词本，进入艾宾浩斯复习流**：
  * 阅读中收藏的生词自动沉淀为“待复习技术卡片”，利用记忆曲线在背单词主流程中再次复现，彻底闭环。

## 5. 明确“不做什么”（Out of Scope 边界）

为确保 MVP 阶段精力聚焦、小步快跑，避免因功能膨胀导致产品臃肿，明确划定以下**坚决不做的边界**：

| 排除项 | 排除理由与原则 |
| :--- | :--- |
| **❌ 坚决不做重度社交与社区广场** | 不做发帖讨论区、动态广场、点赞评论社区，仅保留轻量级个人连续打卡天数与学习进度统计，保持纯粹的效率工具属性。 |
| **❌ 坚决不做在线代码执行与 OJ 环境** | 不提供 LeetCode/在线沙盒式的代码编写与运行编译能力。代码仅作为语法高亮例句辅助理解，避免极高的后端运维与安全沙箱成本。 |
| **❌ MVP 阶段不做大而全的通用考试题库** | 坚决不引入考研政治英语、托福听力口语等泛英语应试题型，始终聚焦“计算机与工程实践”技术词汇。 |
| **❌ MVP 阶段不走纯粹全文机器翻译工具路线** | 阅读板块的核心是“辅助理解与术语提取”，而非代替用户整篇生硬机翻，保持“以词带读、以读促记”的学习本质。 |

## 6. MVP 演进与交付阶段规划

* **Phase 1 (MVP 最小可用版本)**：
  * 建立 Level 1（编程入门语法/报错）与 Level 2（计算机网络/系统/算法核心通识）精选词库；
  * 卡片式背单词核心流（计算机专属释义、代码例句、熟练度标记）；
  * 本地生词本与复习队列。
* **Phase 2 (闭环打通)**：
  * 推出“技术文章阅读”功能，支持自主粘贴文本与外部链接解析；
  * 页面内技术词汇智能高亮、点词即查、一键回炉生词本。
* **Phase 3 (纵深扩展)**：
  * 扩展网络安全（Security）、AI/深度学习、前端工程化等垂直专项词库；
  * 增加技术术语标准音频发音与常见读音避坑提示。
